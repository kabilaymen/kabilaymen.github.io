Projects

Quorum

2026 · Go · Raft, write-ahead log, Docker, Prometheus

A replicated key-value store on an implementation of Raft written from scratch. The consensus core never touches the clock, the network or the disk, so a whole cluster runs inside one test and replays exactly from a seed. That made it possible to throw message loss, partitions and crash-restarts at it and check Raft's safety properties after every step.

  • 1,000 randomized fault scenarios pass; mutation tests confirm the suite catches a forgotten vote or a lost log entry.
  • About 49,000 concurrent operations under partitions, checked linearizable with Porcupine.
  • Durable writes went from 842 to about 3,450 per second once replication was pipelined and fsyncs were batched.

Vigil

2026 · Go, Python · MQTT, Kafka, Prometheus, Grafana

Telemetry and failure detection for a fleet of machines. A crashed machine is easy to notice: the broker publishes its last will. A machine that is still connected but has stopped working is not, because its network thread keeps answering pings. Vigil catches both, the second with a phi accrual detector that learns each machine's heartbeat rhythm.

  • A stalled machine is flagged after about 1.2 s of silence; a crash is reported in about 1 s (50 simulated machines).
  • The detector stops judging the fleet while it is itself behind the stream, so a slow detector cannot raise false alarms.
